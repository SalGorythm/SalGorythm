## About this repo

Monorepo for the portfolio site. The Vite app lives in **`portfolio/`** — see [portfolio/README.md](portfolio/README.md) for local dev (`npm run dev` from repo root).

```bash
git clone https://github.com/SalGorythm/SalGorythm.git
cd SalGorythm
npm run dev    # starts portfolio + local stats API
```

Deployed on Vercel → [salgorythm.com](https://salgorythm.com)
